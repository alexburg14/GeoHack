# GeoHack · Team HolzHaus

Beitrag zum **Geothermie Hackathon Pullach** (13.–14. November 2026), Challenge 3 „NextGen Customer Voice“
(Geothermie Unterhaching).

**[Wärme-Pakt](waerme-pakt/)**: Web-App, mit der Bürgerinnen und Bürger in Unterhaching in wenigen Minuten sehen,
wann die Geothermie in ihre Straße kommt, was ein Anschluss über 20 Jahre kostet, Fragen an einen KI-Berater stellen
und gemeinsam mit ihren Nachbarn zusagen. Ab 65 % Zusagen wird ein Straßenabschnitt gebaut.

```bash
cd waerme-pakt
python3 server.py   # http://127.0.0.1:8000
```

Details, Demo-Ablauf und Datenquellen: [waerme-pakt/README.md](waerme-pakt/README.md).
Alle Preise und Beteiligungszahlen sind Platzhalter für die Demo.
