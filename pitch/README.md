# EnergiePlus – Pitch

`index.html` is the pitch deck as a standalone page: open it in a browser, use ← / → or click to move between slides, F for fullscreen.

`source/` holds the slide files it is built from (`deck.json` sets the order, `deck.css` the shared styles, `slides/` one file per slide; speaker notes are in each slide's `<aside>`).
